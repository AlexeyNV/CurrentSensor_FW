# CurrentSensor GUI v0.1.1

Версия добавляет сохранение после измерения, устойчивый Freeze и статистику RAW
между курсорами. STM32, SPI DMA, CSF4 и коэффициенты Flash не изменялись.
Запуск: `.\.venv\Scripts\python.exe -m current_sensor`; без прибора — добавить `--demo`.
Установка и базовые команды описаны в [GUI.md](GUI.md).

## Сохранение и временная история

«Временная RAW-история» включена по умолчанию. Отдельный поток пишет исходные
отсчёты в `%TEMP%/CurrentSensorGUI/spool`, без создания CSV или CSF4.
Ограничения: очередь 128 блоков, суммарный лимит spool 2 GiB, резерв свободного
места 256 MiB. Проверка места повторяется во время записи. При ошибке диска
приём продолжается; ошибка и неполнота истории показываются явно.
Настройка отключения истории сохраняется для следующих запусков.

- **Сохранить замер / Ctrl+S**: весь доступный префикс текущей сессии на момент
  нажатия, в том числе во время приёма и Freeze. Новые отсчёты принимаются дальше.
- **Сохранить участок / Ctrl+Shift+S**: X1–X2 при включённых курсорах; иначе выбранная
  ROI или видимый X. Режим Auto выбирает активную ROI, затем видимый диапазон.
- **Экспорт PNG**: изображение осциллографа с текущими осями, курсорами и ROI.
- **Открыть эксперимент / Последние эксперименты**: повторное исследование сохранённых данных.

Экспорт выполняется отдельным потоком: CSV + RAW binary + metadata JSON с уникальными
именами. Включаются все исходные точки, одиночные импульсы, отрицательные и подозрительные
значения. Фильтры отображения не изменяют экспорт. RAW-запись содержит little-endian
`slot:u32, tim2_read_us:u32, vshunt_code:i32, time_s:f64`, 20 байт на точку.
CSV хранит исходный код и время; для текущего ADCRANGE=0 ток в мА равен `code / 16`.
CSF4 для такого экспорта не создаётся: воспроизвести исходные CRC/END по RAW нельзя.
Прежняя кнопка «Запись RAW» независимо записывает принимаемые кадры и CSV.

При закрытии реальной сессии приложение останавливает приём и предлагает сохранить,
удалить временную историю или отменить закрытие. Отмена оставляет соединение открытым,
но измерение уже остановлено. Ошибка экспорта отменяет закрытие. После аварии кнопка
«Восстановить» находит оставшиеся RAW-файлы; активные сессии другого процесса исключены.
Восстановленная запись не объявляется полной или завершённой по END. Сохранение и
удаление такой истории снова требуют обычного выбора пользователя при закрытии.
DEMO удаляет собственные синтетические временные файлы при закрытии без вопроса.

Без spool доступно только live-кольцо 600000 точек. При отказе диска полный экспорт
может содержать только сохранённый префикс; свежий хвост можно отдельно сохранить из
live-буфера. Такие результаты помечаются частичными, отсутствующие точки не выдумываются.

## Freeze, курсоры и статистика

Freeze фиксирует данные и оси, приём продолжается. Старый диапазон загружается из spool
в фоне, поэтому вытеснение из live-кольца не уничтожает зафиксированный участок.
Кнопка Live возвращает слежение. Ручной zoom/pan фиксирует просмотр; фактические s/div
и mA/div обновляются по осям. Режимы Y: Manual, Auto (полный диапазон), Robust
(устойчивый масштаб, который может оставить импульсы за границей экрана).

При включённых X1/X2 нижний блок автоматически показывает MIN/MAX/AVG/RMS, N, Δt и GAPS.
Границы `min(X1,X2)..max(X1,X2)` включительные, поиск идёт по реальным timestamps.
RMS = `sqrt(mean(I²))`, включая DC. Расчёт всегда RAW, независимо от MEDIAN3/5,
прореживания, envelope или CALIBRATED. ROI остаётся независимым измерением.
Пустой или недоступный диапазон отмечается явно, неполный расчёт не выдаётся за полный.

GAPS определяется по slot_index без интерполяции и нулевого заполнения.
Если граница курсора проходит внутри разрыва, точное положение отсутствующих timestamps
неизвестно: показывается нижняя оценка, `slot_gaps_complete=false`. Для полностью
ограниченных реальными отсчётами разрывов число пропущенных слотов точное.

Индекс использует блоки по 4096 точек: кеш экстремумов и префиксные суммы/квадраты.
Запрос сканирует только края блока и агрегаты; полный проход при каждом движении не нужен.
Статистика выполняется в отдельном потоке, запросы объединяются, индикаторы обновляются
не чаще 10 Гц. Последнее положение курсоров обязательно обрабатывается.

CALIBRATED меняет только отображение по коэффициентам, зафиксированным при начале
сессии: `(I_raw_mA - OFFSET_UA/1000) * GAIN_PPM/1000000` при ENABLED=1.
При неизвестных коэффициентах используется RAW с сообщением. Статистика курсоров и
экспорт остаются RAW; автоматической записи или смены калибровки нет.

## Metadata

JSON содержит профиль, устройство/соединение, коэффициенты сессии, источник данных,
исходные slots/timestamps и тип экспорта. Типы: FULL_SESSION, FULL_AVAILABLE_PARTIAL,
CURSORS, VISIBLE_RANGE, ROI, FREEZE. Для курсоров сохраняются `cursor_x1_s`,
`cursor_x2_s`, `interval_start_s`, `interval_end_s`, `sample_count`, `min_ma`,
`max_ma`, `avg_ma`, `rms_ma`, `slot_gaps`, `statistics_source=RAW`.

- `source_history_complete`: вся история сессии доступна на момент снимка.
- `interval_data_complete`: выбранные временные границы покрыты доступной историей;
  gaps учитываются отдельно и не скрываются этим флагом.
- `recording_finished`, `recording_saved`, `recorder_error`: завершение именно записи файлов.
- `acquisition_finished`: состояние исходного сбора на момент снимка.
- RAW-экспорт имеет `session_end_verified=false`, `is_csf4_session=false`;
  исходная проверка END хранится в `source_session_end_verified`.
- Прежние промежуточные `state` и `recording` перенесены в `pre_final_snapshot`.

Диагностика устройства/транспорта относится к исходной сессии целиком; это не счётчики
ошибок только выбранного участка. Статистика RAW и slot_gaps относятся к интервалу.

## Проверка на плате

1. Закрыть PuTTY, запустить GUI, подключить COM и проверить FW/профиль/DMA.
2. Выбрать LOW_NOISE, начать приём без «Запись RAW». Через 10–20 с сохранить замер,
   проверить CSV/RAW/JSON и продолжающийся приём без роста CRC/потерь.
3. Включить курсоры, переставить X1/X2, проверить одинаковые N/AVG/RMS. Выбрать
   участок с импульсом; сохранить и сравнить MIN/MAX/AVG/RMS с исходными кодами CSV.
4. Freeze: запомнить оси/участок, продолжать приём дольше ёмкости live-кольца
   (60 с при FAST 10 кГц, 600 с при LOW_NOISE 1 кГц). Проверить старую статистику,
   сохранение участка и возврат Live.
5. Остановить, сохранить весь замер, открыть JSON заново. Сравнить N, slots и статистику.
   Проверить PNG с курсорами и ROI, ручной Y/Auto/Robust и фактические деления после zoom.
6. Повторить с выключенной временной историей: недоступный участок должен быть явно
   помечен. Проверить Save/Discard/Cancel при закрытии и восстановление тестовой
   временной записи после аварийного завершения приложения.
7. FAST DMA: 60 с с перемещением курсоров и экспортом. Проверить отдельно CRC/USB,
   пропуски измерительных слотов, ошибки spool/recorder и подозрительные токи.

1000 Гц, без CRC/SPI/DMA и внутрипоточных пропусков. **GUI v0.1.1 на плате ещё не проверен.**
Автотесты и измерения производительности: [GUI_0.1.1_BENCHMARK.md](GUI_0.1.1_BENCHMARK.md).
