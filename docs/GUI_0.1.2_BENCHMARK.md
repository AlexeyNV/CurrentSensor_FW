# GUI v0.1.2 — тесты и benchmark

Windows 10, Python 3.12, Qt windows, синтетический DEMO FAST 10 кГц. Исходные
измерения: [GUI JSON](gui_012_benchmark_windows.json),
[детектор JSON](gui_012_anomaly_benchmark.json).

Детектор обрабатывал последовательные блоки RAW, включая один код −8269 среди
нормальных −77. Для каждого размера проверены количество событий и покрытие всех
отсчётов; 200 случайных запросов обработанной статистики сверены по количеству.

| RAW-отсчётов | Анализ, с | Скорость, отсчётов/с | Средний запрос, мс | p95, мс |
|---:|---:|---:|---:|---:|
| 100000 | 0,051 | 1,97 млн | 1,17 | 1,99 |
| 600000 | 0,307 | 1,95 млн | 1,25 | 1,93 |
| 3000000 | 1,479 | 2,03 млн | 1,26 | 2,06 |
| 10000000 | 4,896 | 2,04 млн | 1,25 | 2,04 |

Численный анализ истории проходит быстрее поступления 10 кГц. Открытие файла и
построение кеша отображения в эту таблицу не включены.

В оконном DEMO по 5 с на таймер с движением курсоров, spool и двумя экспортами:

| Таймер, мс | Обновления графика/с | Отсчётов | Детектор обработал | CRC | GAPS |
|---:|---:|---:|---:|---:|---:|
| 16 | 31,13 | 51250 | 51250 | 0 | 0 |
| 20 | 28,91 | 51250 | 51250 | 0 | 0 |
| 33 | 26,86 | 51250 | 51250 | 0 | 0 |

Для всех трёх вариантов ошибка детектора и spool отсутствовала, а экспорт RAW
прошёл сверку статистики. Таймер 16 мс выбран по умолчанию: в этом сценарии
он сохранил около 30 обновлений/с, достигнутых в v0.1.1. Это короткий тест на
одном ПК; частота GUI и USB на реальном приборе ещё не подтверждены.

В итоговом прогоне прошли **57 GUI-тестов** и **20 тестов CLI**. Аппаратные
испытания GUI v0.1.2 не проводились.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests_gui -q
.\.venv\Scripts\python.exe -m unittest discover -s tools -p 'test_*.py' -q
.\.venv\Scripts\python.exe -m tools.benchmark_anomaly_012
.\.venv\Scripts\python.exe -m tools.benchmark_gui_011 --output docs/gui_012_benchmark_windows.json
```

Новые тесты проверяют ±выброс, изменение кода на 8192, реальный односэмпловый
импульс, два соседних события, границы пакета/кольца, разрыв slot, три профиля
подряд, замену сессии, обе статистики, event CSV, старый JSON, 10 млн точек,
живой DEMO 10 кГц, Freeze/историю/навигацию и отдельный отчёт STM32.
