# CurrentSensor GUI 0.6.2

GUI 0.6.1 доработан без замены транспорта, декодера, recorder и измерительного
ядра. FW остаётся **0.5.0**; SPI/DMA/Native, CSF4 v2, Flash sector 7 и
калибровка не изменялись. Новых зависимостей нет. Commit/push не выполнялись.

## A. Почему настройки обрезались и что исправлено

В 0.6.1 вкладки находились в QScrollArea с `maximumHeight=190`. При этом
обычный QTabWidget учитывал размеры самого большого раздела. Маленький
viewport не соответствовал реальной высоте форм: появлялись полосы прокрутки,
а переключение вкладок не давало активному содержимому нужное место.

Теперь SettingsPage располагает **те же существующие элементы управления**
в подписанных адаптивных ячейках, по одной–три колонки. SettingsTabs вычисляет
sizeHint/minimumSizeHint по активному разделу. Высота зависит от содержимого,
а не от постоянного предела 190 px. Внутри настроек нет QScrollArea.
Обычные выпадающие списки сохраняют собственные popup-списки.

На широком окне настройки раскрываются внутри главного окна. Если это
оставило бы главный график слишком маленьким, те же вкладки перемещаются
в **немодальное изменяемое окно «Настройки CurrentSensor»**. Копии значений
и вторые обработчики параметров не создаются. Окно размещается с учётом
QScreen.availableGeometry. При изменении ширины пересчитываются колонки
и необходимая высота; слишком узкий вариант при необходимости расширяется,
чтобы весь активный раздел оставался доступным.

Повторное нажатие кнопки, крестик или Esc сворачивают настройки. Раздел,
значения и сигналы сохраняются. Acquisition/запись не останавливаются,
MANUAL/LIVE FOLLOW и X не меняются. Освободившееся место возвращается графику;
сохраняется соотношение частей QSplitter и его существующая настройка QSettings.
Размер правой панели при переключении разделов не меняется.

Профиль и режим прибора блокируются существующим обработчиком состояния при
работающем acquisition. Добавлена подсказка о необходимости остановки.
Безопасные настройки отображения и само окно доступны во время записи.

## B. Overview Robust Y / Full RAW

Режим обзора выбран отдельно от Y основного графика:

- **Robust Y**, по умолчанию: существующая robust_y_range оценивает Y по
  основной массе RAW. SUSPECT из существующего каталога отмечены маркерами
  внутри видимой границы. Исходные значения кривой не заменяются и не удаляются.
- **Full RAW**: полный диапазон экстремумов с небольшим отступом.

Переключение изменяет только overview. X и Y основного графика сохраняются.
Времена extremum/envelope и разрывы берутся из существующего renderer/index.
Никакого нового алгоритма SUSPECT нет. Оценка масштаба — не статистика ряда:
для массива используется ограниченная выборка существующего robust_y_range;
для сегментированного архива чтение до 32 блоков выполняет StatisticsWorker.
Полная статистика по-прежнему считается по всем исходным отсчётам.

Проверена исходная ZERO_BEFORE: 715198 отсчётов, пять SUSPECT, максимум
**26313,8125 мА**. Full RAW: Y примерно **−2659…28460 мА**;
Robust Y: **−5,10…5,225 мА**. Обычный шум виден, а огромные значения
не исчезают из записи и доступны через маркеры/Full RAW.

[Full RAW](../results/gui_062/overview_Full_RAW.png) и
[Robust Y той же записи](../results/gui_062/overview_Robust_Y.png).

Маркер использует тот же объект события, что каталог/sidecar. Нажатие
переходит к его окрестности на основном графике и включает RAW-курсоры.
Показаны sequence, timestamp, RAW24 и ток, если они доступны в источнике.
Проверено событие sequence=637882, TIM2=296144546 мкс,
RAW24=0x66C9D0, CODE=421021, ток=26313,8125 мА.
[Переход к исходному RAW](../results/gui_062/overview_marker_raw.png).
Для v1/старых CODE-only файлов RAW24 честно остаётся недоступным.

Robust Y может визуально обрезать редкий реальный импульс по Y; это не
исключение измерения. Маркер означает SUSPECT, а не доказанную ошибку SPI.

## C. Сравнение статистики

В верхней части правой панели доступны «Полный RAW», «Диагностика без SUSPECT»
и «Сравнить RAW / без SUSPECT». Они используют результаты того же
StatisticsWorker и существующего каталога, без повторного детектора и без
фильтрации файлов. Показаны исходный N, SUSPECT и число использованных значений.
Исключение из расчётов явно подписано как диагностическое; ошибки измерения
не считаются доказанными.

Пример для ZERO_BEFORE:

| Показатель | Полный RAW | Без SUSPECT |
| --- | ---: | ---: |
| Исходных отсчётов | 715198 | 715198 |
| SUSPECT | 5 | 5 |
| В расчёте | 715198 | 715193 |
| AVG, мА | −0,027738 | −0,099794 |
| MEDIAN, мА | 0,0625 | 0,0625 |
| MIN, мА | −513,1875 | −7,25 |
| MAX, мА | 26313,8125 | 7,375 |
| RMS, мА | 43,089263 | 1,636358 |
| STD, мА | 43,089254 | 1,633312 |

Частота/длительность описывают исходный интервал, без искусственного сжатия
времени после исключения. Срез и актуальность расчёта по-прежнему подписаны.
[Сравнительное отображение](../results/gui_062/statistics_comparison.png).
Экспорт исходного участка не исключает SUSPECT из RAW/CSV.
