# Аппаратная часть

Источник сведений — предоставленная автором схема EasyEDA:
[SCH_Current_sensor_pres_2026-11-14.json](gerber/SCH_Current_sensor_pres_2026-11-14.json).
Производственные файлы платы:
[Gerber ZIP](gerber/Gerber_Current_sensor_pres_PCB_Current_sensor_pres_2026-11-14.zip).
JSON можно импортировать в совместимую версию редактора EasyEDA; это исходный
документ схемы, не изображение.

STM32F411RET6 получает VSHUNT от INA229 по SPI1, mode 1, 6 МГц. Шунт — 5 мОм.
Готовность результата Native отслеживается по ALERT; SPI DMA читает регистры,
TIM2 задаёт временную шкалу получения результата MCU. USB CDC передаёт данные
и принимает ASCII-команды. Подключения GPIO находятся в CubeMX
[CurrentSensor_FW.ioc](../CurrentSensor_FW.ioc) и [Core/Inc/main.h](../Core/Inc/main.h).

В предоставленной схеме USB-изоляция выполнена на **ADUM3160BRWZ (U11)**,
питание изолированной стороны — **B0505S-1WR3L (U10)**; обозначены сети
`ISO_VDD` / `ISO_GND`. Это описание реализованной схемы. Испытания напряжения
изоляции, путей утечки, защитных категорий и электрической безопасности
данным релизом не проводились. Номинал отдельного компонента не является
сертификацией собранного прибора.

Рабочий измерительный режим релиза: ADCRANGE=0, Native DMA, VSHCT=84 мкс,
AVG=1, ALATCH=1, VERIFY OFF. Timestamp — момент обслуживания/получения результата
MCU, а не точный физический момент преобразования INA229.
