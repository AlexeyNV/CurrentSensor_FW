# Испытания CurrentSensor 1.0.0

Дата: 14 ноября 2026. STM32F411RET6 + INA229, SPI1 6 МГц, Native DMA,
VSHCT=84 мкс, AVG=1, ALATCH=1, VERIFY OFF, ADCRANGE=0. Итог:
**QUALIFIED WITH WARNINGS**, не безусловная метрологическая аттестация.

## Испытанный бинарный файл

`CurrentSensor_FW_1.0.0.elf`:

```text
SHA-256 a0017ea7cbbc4419de551c9fd26c165702cf50f12131bc2b91db0fc49971a433
```

Это новый ELF 1.0.0, реально записанный и испытанный. Проверка старого ELF
0.5.0 не подменяет этот результат. Измерительные исходники не менялись при
поднятии версии: изменены только APP_FW_VERSION / APP_FW_BUILD в app.h.
Release ELF получен из фиксированной по дате сборки удалением debug-секций.
Повторная чистая сборка в другом build-каталоге дала тот же SHA-256.
SOURCE_DATE_EPOCH=1794614400; GCC for STM32 14.3.1; параметры — в build_manifest
релизного набора. Обычный `make` без фиксированной даты может дать иной ELF.

Запись: STM32CubeProgrammer 2.23.0, ROM DFU. Подтверждены Device ID 0x0431,
явный serial, единственный DFU target и диапазоны ELF. Последний загрузочный
байт ниже 0x08019268; sector 7 начинается с 0x08060000. Сохранены 131072 байта
сектора 7; стёрты только секторы 0–4, запись `--skipErase -d ... -v`.
Mass erase и option bytes не использовались.

SHA-256 сектора 7 **до и после совпал**:

```text
6d25dad15300736cfa485ab994c4cd3b83ec7e7e5d91d5beeb64c1602350e28a
```

Резервные копии Flash не публикуются. INFO после записи показал 1.0.0;
идентификация INA229, обычное measure и восстановление диагностического
ADC_CONFIG после Stop прошли.

## Результаты

| Проверка | Результат |
|---|---|
| `make -j4` и отдельная release-сборка | Успешно; предупреждений сборки не обнаружено |
| C host tests | 16/16 PASS |
| GUI regression | 130/130 PASS |
| CLI/HIL/analysis regression | 49/49 PASS |
| Новый FW smoke-test | PASS, Native RATE_HZ=11911 |
| Native 60 с | 715505 RAW; 11912.2354 Гц; END получен |
| Целостность 60 с | CRC/frame/sequence/timestamp/resync errors=0; ADC/USB/CSV counts совпали |
| Ошибки измерения/переполнения 60 с | SPI/DMA errors/timeouts=0; runtime losses и queue/buffer drops=0 |
| GUI короткая запись | START/STOP/END, запись и Disconnect/Reconnect прошли |
| GUI сегментированная запись | 68685 RAW сохранены; END; нет CRC/sequence/recorder drops; архив консервативно PARTIAL |
| Настройки во время реальной записи | Все 5 страниц; streaming и запись продолжались; отдельных окон нет |
| Неподдержанный POLL/FAST | Start/Apply отключены локально, COM сохранён |

В 60-секундном тесте есть **45 service cycles >=84 мкс** и **4 подозрительных
значения вне контрольного окна -50..10000 мА**. Это предупреждения, не
переименованные в SPI/DMA errors; данные сохранены без исправлений.
Число результатов не доказывает отсутствие потери всех внутренних конверсий
INA229. Нормальные отрицательные значения около нуля остаются допустимыми.

Сегментированный GUI-архив получил PARTIAL, несмотря на все сохранённые RAW и
проверенный END: консервативная проверка archive учитывает END.LOST_SAMPLE_SLOTS=1
(Native STOP-discard), тогда как worker отдельно различает runtime loss и
отброшенный при Stop хвост. Это существующее ограничение сохранено, а не скрыто
заменой статуса на COMPLETE. Его проявление и исходные счётчики включены в JSON.

## Панель настроек

SettingsDialog удалён. Весь набор виджетов остаётся дочерним основному окну:
при достаточной высоте — inline; при недостатке — страница вместо графика,
при необходимости временно скрывающая правый dock статистики. Кнопки
измерения/записи остаются в основном окне. Закрытие возвращает прежний график,
выбранную страницу, курсоры, интервал и LIVE/MANUAL; USB не закрывается.

Проверена матрица 1366×768, 1694×1188, 1920×1080 × шрифт 100%,125%,150% ×
5 страниц: **45 сочетаний PASS**, ни одного отдельного окна, внутренней полосы
прокрутки или изменения размера main window. Это Qt font stress/offscreen
проверка, не сертификация всех вариантов нативного Windows DPI.
